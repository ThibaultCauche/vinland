# share-inbox

Boite de reception des partages cibles : un ami envoie un titre, un album ou
une playlist a un autre ami precis, qui le retrouve dans l'app.

> Le code (`server.py`) doit encore etre copie ici depuis le NAS : voir
> « Ajouter le code des services » dans `services/README.md`.

Client dans l'app : `lib/services/share_inbox_service.dart`.
