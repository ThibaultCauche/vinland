# Vinland 2.0 : le mode Soirée

La mise à jour arrive toute seule : sur Windows l'app se relance en 2.0,
sur Android il suffit de confirmer l'installation. Tu gardes tout (likes,
playlists, hors-ligne, réglages).

## Nouveau : le mode Soirée 🎉

- **L'hôte lance une soirée** (menu Jam > « Mode soirée ») et affiche un
  QR code.
- **Les invités scannent le QR** (ou tapent le code), choisissent un
  pseudo, cherchent un titre et le proposent. Pas besoin de compte.
- **La file est équitable** : chacun son tour, les votes départagent, pas
  de doublon. L'hôte peut mettre un veto, lancer un titre tout de suite ou
  exclure quelqu'un.
- **Écran d'ambiance pour la télé** : grande pochette, qui a proposé le
  titre, les suivants et le QR pour rejoindre.
- **Radio automatique** quand la file est vide : des titres proches de ce
  qui vient de passer, jamais deux fois le même.
- **Récap de fin de soirée** : une playlist « Soirée du JJ/MM » avec qui a
  proposé quoi, à partager.
- **Pack hors-ligne** : télécharge une playlist à l'avance si le réseau
  du lieu est mauvais.

## Écouter mieux

- **Plus de blanc entre deux titres** : le suivant est préparé à l'avance.
- **Fondu enchaîné** réglable (Paramètres > Lecture), jamais au milieu
  d'un album live.
- **Volume égalisé** entre les titres (Paramètres > Lecture).
- **Jam mieux synchronisé** : les téléphones restent calés sans
  micro-coupures. Si ton casque Bluetooth est en retard, règle « Décalage
  audio » dans le menu Jam.

## Plus sûr

- **Tu choisis ce que tu partages** avec les amis (likes, écoutes, titre
  en cours) : l'app te pose la question une fois après la mise à jour.
- Personne ne peut plus prendre la main sur ton Jam ou ta synchro entre
  appareils juste en connaissant le code.
- Les mises à jour sont **signées** : l'app refuse un fichier modifié.

## Corrigé

- L'app ne perd plus les likes, le hors-ligne ni les playlists si elle
  est coupée pendant une synchro.
- Les grosses playlists se mettent à jour, sans doublons après une
  coupure réseau.
- « Reprendre ici » reprend bien le titre sur l'appareil où tu es.
- Import de playlist : plus d'accents cassés sur les gros fichiers.
