# Vinland 2.3 : ta musique sans réseau

La mise à jour arrive toute seule : sur Windows l'app se relance en 2.3,
sur Android il suffit de confirmer l'installation. Tu gardes tout (likes,
playlists, réglages, titres déjà téléchargés).

## Écouter hors-ligne

- **Télécharge un album, une playlist ou tes titres likés** avec la
  flèche ⬇ (sur PC : menu « ... » > Télécharger). Les pochettes viennent
  avec, et les nouveaux titres ajoutés plus tard se téléchargent tout
  seuls à la synchro suivante.
- **Sans réseau, ça joue quand même** : si le serveur ne répond plus,
  Vinland passe en hors-ligne. Seuls les titres téléchargés se lancent,
  les autres sont grisés et sautés. Dès que le serveur revient, tout
  redevient normal sans rien toucher.
- **Mode hors-ligne** à activer toi-même (Paramètres > Téléchargements)
  pour ne pas consommer de 4G.
- **Page « Musique téléchargée »** (Paramètres, Bibliothèque, ou menu du
  profil sur PC) : ce qui est sur l'appareil, la place prise, la qualité
  (128, 192 ou 320 kbps) et un bouton pour tout supprimer.
- Une petite flèche verte montre les titres disponibles hors connexion.
