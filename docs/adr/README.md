# Décisions d'architecture (ADR)

Une ADR par choix structurant déjà fait, pour savoir **pourquoi** le code
est comme il est avant de le changer. Format court : contexte, décision,
conséquences. Une décision remplacée n'est pas supprimée : on ajoute une
nouvelle ADR qui la remplace et on le note dans l'ancienne.

| N° | Décision | Statut |

| [0002](0002-runner-windows-2022.md) | Runner GitHub `windows-2022` pour les releases | Acceptée |
| [0003](0003-un-seul-titre-dans-le-moteur.md) | Un seul titre chargé dans le moteur audio | Acceptée |
| [0004](0004-tailscale-funnel.md) | Accès distant par Tailscale Funnel | Acceptée |
| [0005](0005-playlists-miroirs-pour-le-social.md) | Playlists miroirs pour les fonctions sociales | Acceptée |
| [0006](0006-transcodage-192-kbps.md) | Transcodage mp3 192 kbps | Acceptée |
| [0007](0007-garder-identifiant-android.md) | Garder l'identifiant Android `com.example.vinland` | Acceptée |
